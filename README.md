# Hairline Client

Hairline Client is the public web app for customers looking for barbers, hairdressers, and stylists.

The downloaded stylist app is a separate project at:

`C:\Users\kathr\Documents\Claude CoWork Files\Projects\Apps\Hairline stylist`

## Client Promise

Find a hairstylist who knows your hair and never lose them.

Customers search stylists and barbers, not salons. They can filter by hair type, style goal, comfort needs, reviews, photos, and location, then book directly with the professional.

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- Supabase-ready configuration placeholders
